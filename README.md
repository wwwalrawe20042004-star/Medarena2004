# بوت تليگرام لتوزيع أكواد الاستخدام الواحد

المستخدم يرسل `/start`، يضغط «ابدأ»، ويختار واحدة من خمس مراحل. البوت يرسل كود واحد من المرحلة المختارة بالمحادثة الخاصة ويشيله من المخزون. كل قائمة مراحل تسمح بطلب واحد ناجح. إذا المستخدم يريد طلب جديد، يقدر يرسل `/start` من جديد.

## تعبئة المخزون

تحتاج Python 3.9 أو أحدث. خلي أكواد كل مرحلة بملف نصي UTF-8، كود واحد بكل سطر. شغّل الأوامر من مجلد المشروع بعد ما تجهّز الملفات.

```bash
python3 bot.py add 1 stage1.txt
python3 bot.py add 2 stage2.txt
python3 bot.py add 3 stage3.txt
python3 bot.py add 4 stage4.txt
python3 bot.py add 5 stage5.txt
python3 bot.py stock
```

تقدر تضيف أكواد جديدة والبوت شغّال. إذا كررت كود بملف أو بمرحلة ثانية، البوت يتجاوزه حتى لو كان مصروف من قبل. خلي ملف قاعدة البيانات `codes.sqlite3` بمكان دائم لأن بيه المخزون وسجل الأكواد المصروفة.

## تشغيل البوت

1. افتح [@BotFather](https://t.me/BotFather) بتليگرام، أرسل `/newbot` واتبع الخطوات حتى تحصل على التوكن.
2. انسخ `.env.example` إلى `.env` مرة وحدة بالأمر `(umask 077 && cp -n .env.example .env)`. افتح `.env` والصق التوكن بعد `BOT_TOKEN=` واحفظ الملف. خلي هذا الملف عندك.
3. شغّل الأوامر التالية في Bash من مجلد المشروع حتى تحمّل `BOT_TOKEN` وتشغّل البوت.

   ```bash
   set -a
   source ./.env
   set +a
   python3 bot.py run
   ```

4. افتح بوتك بتليگرام وأرسل `/start`.

شغّل نسخة واحدة من البوت لكل توكن وخليها شغّالة حتى ترد على المستخدمين. إذا تليگرام رفض الإرسال بشكل صريح، يرجع الكود للمخزون. إذا انقطع الاتصال وما قدر البوت يتأكد من نتيجة الإرسال، يبقى الكود خارج المخزون حتى ما ينصرف مرتين.
